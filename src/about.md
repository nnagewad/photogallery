All the photos here were taken by [me](https://nikin.design).

There’s no particular theme or big idea behind this gallery. These photos capture everyday moments I’ve noticed and felt like sharing.

The technology behind this site includes:

- [Exifr](https://www.npmjs.com/package/exifreader) — for extracting the photo’s metadata
- [OpenCage](https://opencagedata.com) — to translate GPS coordinates into human-readable locations
- [Claude AI](https://docs.anthropic.com/en/home) — for generating titles, alt-text, and tags for each photo
- [11ty](https://www.11ty.dev/) — the static site generator used to build this website

These are simply photos I enjoyed taking and editing, and I hope you might enjoy them too.
